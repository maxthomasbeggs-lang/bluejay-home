📅 Add Everything to Your Calendar

Exports every upcoming game and event — with times and location — in one go.

Apple/Outlook: a file downloads — open it and your calendar app will ask to add every event.
Google: click the button — it downloads the same file and opens Google Calendar's import page for you.

  1. A file named Bluejays-Calendar.ics just downloaded to your Downloads folder.
  2. A new tab just opened to Google Calendar's Import & Export page.
  3. In that tab, click "Select file from your computer" and choose the file you just downloaded.
  4. Choose which calendar to add the events to, then click Import.
Heads up: Google Calendar's file import only works on a desktop computer. Your file still downloaded to your phone. Two options:
• Easiest on iPhone: use the Apple Calendar / Outlook button above instead.
• For Google specifically: open this page on a computer later and click "Add to Google Calendar" there.
